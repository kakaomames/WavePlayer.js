# kakaomame-wave-player 使い方まとめ

1. 基本の呼び出し方

* 呼び出し: await WP(周波数Hz, 再生秒数s, 音量0.0〜1.0, カスタム波形関数[任意])
* 第1引数（周波数Hz）: 20〜20000（デフォルト: 440）
* 第2引数（再生秒数s）: 0.005以上（デフォルト: 0.4）
* 第3引数（音量倍率）: 0.0〜1.0（デフォルト: 0.3）
* 第4引数（カスタム波形関数）: (t, freq, sampleRate) => -1.0〜1.0（任意、デフォルト: null）

2. HTML / CDN での使い方

* ES Module 形式のため  で読み込む
* jsDelivr 例:
* ミニファイ版を使う場合は main.min.js や WavePlayer.min.js を指定する
* クリックやタップなどのユーザー操作イベント内で WP(...) を呼び出す

3. ブラウザ・iPad 利用時の注意点

* ユーザー操作内で呼ぶことで AudioContext の resume と無音バッファ解除が動きやすい
* ctx.resume() が応答しない環境に備えてタイムアウトを入れておくと固まりを防げる
* iPadOS Safari の Web Audio API は消音（サイレント）モードの影響を受けるため、音が鳴らないときは消音解除・メディア音量・Bluetooth 出力先を確認する
